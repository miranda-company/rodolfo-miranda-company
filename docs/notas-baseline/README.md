# Notas design baseline

The Notas index (`/notas`) and the `El umbral entre una idea y un sistema` reading template (`/notas/umbral`) are the approved design baseline for this section.

The 24 additional development notes are draft design fixtures. Development intentionally shows all 27 notes, while normal production builds include only the three non-draft entries: `umbral`, `margen`, and `archivo`. The current summaries and article copy for those three entries remain provisional editorial content and require Rodolfo's approval before launch.

Create a high-fidelity, interactive desktop homepage for the personal website “Rodolfo Miranda Company.”

Use the attached wireframe as the structural reference, but not as the visual style. Preserve its essential hierarchy:

1. A slim horizontal header.
2. A large introductory area with the name and positioning.
3. One horizontal row of four large navigation panels:
   “Yo”, “Notas”, “Biblioteca” and “Contáctame”.
4. Generous negative space around the composition.

CONCEPT

The website is a “Digital Garden” for Rodolfo Miranda: digital strategist, designer and creator of useful systems.

The visual concept is “Archivo vivo” — a cultivated editorial archive where ideas, projects, notes and references grow and connect over time.

Combine these influences:

- Independent editorial publication.
- Research notebook and personal archive.
- Modernist information design.
- Subtle retro-digital references.
- Painterly color fields inspired by Tamayo and Rothko.
- Visible relationships between ideas, similar to a hypertext knowledge system.

The garden metaphor must appear through information architecture, connections, growth states and changing content. Do not use literal plants, leaves, vines or generic green branding.

FRAME AND GRID

- Desktop frame: 1440 × 1024 px.
- Use a responsive 12-column grid.
- Page margins: 28–32 px.
- Use Auto Layout throughout.
- Use an 8 px spacing system.
- Keep the main composition within the first viewport.
- Give the layout generous editorial whitespace.
- Use asymmetry in small details while keeping the overall structure precise.

COLOR SYSTEM

Use a warm, almost monochrome editorial foundation:

- Warm paper background: #F7F3EA
- Alternate paper surface: #EEE8DC
- Carbon ink: #1D1E19
- Secondary graphite text: #6E6B62
- Fine borders and connecting lines: #CFC7B8

Use painterly accent colors sparingly:

- Ultramarine: #244C88
- Paprika red: #B63E2C
- Aubergine: #5D2B4C
- Ochre: #D1A139

Approximately 80% of the interface should remain neutral. Color should feel like occasional blooms inside a calm archive, not like a colorful dashboard.

Use ochre only with dark text. Maintain strong, accessible contrast throughout.

TYPOGRAPHY

Use:

- Spectral for the wordmark, main heading, card titles and editorial text.
- Instrument Sans for navigation, descriptions and interface controls.
- IBM Plex Mono for dates, indexes, status labels and metadata.

Recommended hierarchy:

- Main title: Spectral Medium, 72–88 px, tight line-height.
- Positioning statement: Instrument Sans Regular, 28–34 px.
- Card titles: Spectral Medium, 32–42 px.
- Card descriptions: Instrument Sans, 16–18 px.
- Metadata: IBM Plex Mono, 11–13 px, slightly letter-spaced.

HEADER

Design a slim header approximately 64 px high.

On the left, create a compact identity consisting of:

- A small rectangular symbol that can suggest a garden plot, book, index card or digital window.
- A restrained “RM” monogram or abstract path inside the rectangle.
- The wordmark “Rodolfo Miranda Company”.

The symbol must work in one color first. An optional colored version may divide the rectangle into ultramarine and paprika fields.

On the right, add three understated navigation links:

- Índice
- Experimentos
- Ahora

Use Instrument Sans or IBM Plex Mono. Add a fine underline or small directional mark on hover. Separate the header from the page using a subtle 1 px archive rule rather than a heavy colored bar.

HERO

Create a spacious, left-aligned introduction below the header.

Add a small metadata line above the main title:

“MADRID · JARDÍN DIGITAL · EN CRECIMIENTO”

Set this in IBM Plex Mono using graphite text.

Main heading:

“Rodolfo Miranda”

Positioning statement:

“Estratega digital, diseñador y creador de sistemas útiles.”

The title should feel editorial, confident and human. Do not make it look like a technology startup hero. Do not add a conventional CTA button.

Optionally include a very thin line extending from the metadata or title toward the navigation panels, suggesting that the sections are connected to the central identity.

FOUR NAVIGATION PANELS

Place four tall panels in a single horizontal row, following the wireframe.

- Equal width.
- Approximately 330–370 px tall.
- 20–24 px gaps.
- Square corners or a maximum 2 px radius.
- Fine 1 px borders.
- No drop shadows.
- Avoid the appearance of generic SaaS cards.

Each panel should feel like an entry in an archive and contain:

- A two-digit index.
- A section title.
- A one-line description.
- A small metadata or status detail.
- A simple abstract visual system.
- A discreet arrow or directional indicator.

PANEL 01 — YO

Title:
“Yo”

Description:
“Trayectoria, proyectos y forma de trabajar.”

Metadata:
“PERFIL · EN EVOLUCIÓN”

Visual treatment:
Use warm neutral tones and an editorial portrait placeholder or a cropped monochrome image area. Do not invent a realistic likeness. Present the image as an archival specimen with a small caption.

Accent:
Carbon ink and aged paper, with a very small aubergine detail.

PANEL 02 — NOTAS

Title:
“Notas”

Description:
“Ideas en proceso, conexiones y apuntes.”

Metadata:
“ÚLTIMA NOTA · 31.07.2026”

Visual treatment:
Show a small network of thin lines, nodes, annotations or fragments of text. It should suggest connected thinking and hypertext, not a technical network diagram.

Accent:
Ultramarine.

PANEL 03 — BIBLIOTECA

Title:
“Biblioteca”

Description:
“Libros, referencias y recomendaciones.”

Metadata:
“LECTURAS · REFERENCIAS”

Visual treatment:
Use abstract book spines, a cropped cover or stacked rectangular fields. Treat books as cultural objects rather than ecommerce products.

Accent:
Ochre with small ultramarine details.

PANEL 04 — CONTÁCTAME

Title:
“Contáctame”

Description:
“Cuéntame qué quieres construir.”

Metadata:
“DISPONIBLE PARA CONVERSAR”

Visual treatment:
Use a deep painterly field or two overlapping color blocks with a restrained directional arrow. Make this the most expressive panel, while retaining readable contrast.

Accent:
Paprika and aubergine.

INTERACTIONS

Create the panels as interactive components with Default, Hover, Focus and Pressed variants.

On hover:

- Expand the panel’s accent field without covering the entire card.
- Move the title or arrow by approximately 6–8 px.
- Reveal one additional metadata line.
- Animate one connecting rule or path.
- Use a calm 180–240 ms ease-out transition.

On keyboard focus:

- Show a clearly visible 2 px outline using ultramarine or carbon ink.

For the header links:

- Animate a fine underline from left to right.
- Keep movement subtle and editorial.

Connect each panel to a placeholder destination frame named:

- Yo
- Notas
- Biblioteca
- Contacto

VISUAL DETAILS

- Add an extremely subtle paper grain or dot-grid texture at very low opacity.
- Use thin rules, marginal labels, small dates and archive indexes.
- Allow a few elements to extend into the margins.
- Use painterly colors as flat or softly textured fields rather than glossy gradients.
- Keep icons minimal, geometric and consistent.
- Use Spanish interface copy throughout.

AVOID

- Literal botanical illustrations.
- Leaf icons and green “eco” branding.
- Glassmorphism.
- Large rounded cards.
- Heavy shadows.
- Neon colors.
- Startup-style gradient backgrounds.
- Generic portfolio thumbnails.
- Excessive retro-computer styling.
- Decorative connections that do not communicate relationships.

The final result should feel like a cross between an independent editorial publication, a researcher’s notebook and a living personal knowledge system: intelligent, tactile, warm, restrained and distinctly personal.

Build the design using named color variables, text styles, Auto Layout and reusable component variants so it remains easy to extend into the rest of the website.
